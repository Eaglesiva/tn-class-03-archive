## அலகு 1: குடும்பம்

### மதிப்பீடு (Evaluation)

**மூலப்பக்கம்:** [பக்கம் 18](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_18/page_18.html), [பக்கம் 19](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_19/page_19.html)

#### I. சரியான விடையைத் தேர்ந்தெடுக்க

1. சமுதாயத்தின் அடிப்படை அலகு ___________ ஆகும்.
   - அ) கிராமம்
   - ஆ) நகரம்
   - இ) குடும்பம்

2. ___________ நமது அடிப்படைத் தேவைகளில் ஒன்று.
   - அ) சாய்வுஇருக்கை (சோபா)
   - ஆ) இருப்பிடம்
   - இ) மகிழுந்து

3. தாய், தந்தை மற்றும் குழந்தைகள் சேர்ந்து வசிப்பது ___________.
   - அ) சிறிய குடும்பம்
   - ஆ) பெரிய குடும்பம்
   - இ) கூட்டுக்குடும்பம்

4. ___________ தமிழர்களின் மிகச்சிறந்த பண்பு ஆகும்.
   - அ) விருந்தோம்பல்
   - ஆ) விழாக்கள் கொண்டாடுவது
   - இ) கோயிலுக்குச் செல்லுவது

5. குடும்பத்தை நடத்த ___________ திட்டமிடுவது பொருளாதாரத்தை மேம்படுத்தும் வழியாகும்.
   - அ) செல்வத்தை
   - ஆ) பணத்தை
   - இ) வரவு-செலவு

#### II. பொருத்துக

| எண் | தொடர் | பொருத்துக பட்டியல் |
| :---: | :--- | :--- |
| 1 | பண்பு | ஒற்றுமையுடன் வாழ்வது |
| 2 | வேலையைப் பகிர்வது | மாமா |
| 3 | தாய்வழி உறவுமுறை | காய்கறி வியாபாரி |

| 5 | அண்டை வீட்டுக்காரர் | மரியாதை |

---

#### III. சரியா / தவறா என்று எழுதுக

1. ஒரு குடும்பமானது அடிப்படைத் தேவையைப் பூர்த்தி செய்யும்.

2. நமது அண்டை வீட்டுக்காரர்கள் நமது உறவினர்கள்.

3. நமது வரவு-செலவைத் திட்டமிடுவதால் பொருளாதாரம் உயரும்.

4. நாம் நமது பொருட்களை எங்கு வேண்டுமானாலும் வைத்துக் கொள்ளலாம்.

5. எளிமையே ஒவ்வொரு குடும்பத்தின் சிறந்த கொள்கையாகும்.

---

#### IV. பின்வரும் வினாக்களுக்கு விடையளிக்க

1. குடும்பத்தின் வகைகளை எழுதுக.

2. கூட்டுக்குடும்பம் என்றால் என்ன?

3. நமது குடும்பத்திலிருந்து நாம் கற்றுக்கொள்ளும் பண்புகள் யாவை?

4. அண்டை வீட்டுக்காரர்கள் என்போர் யாவர்?

5. குறிப்பு வரைக : ‘குடும்ப வரவு-செலவுத் திட்டம்’.

---

#### V. செயல் திட்டம் / செயல்பாடு

1. உனது குடும்ப வரவு-செலவுத் திட்டத்தைக் கீழ்க்காணும் அட்டவணையின்படி தயாரிக்கவும்:

| வரவு (ரூபாய்) - இனம் | தொகை | செலவு (ரூபாய்) - இனம் | தொகை |
| :--- | :--- | :--- | :--- |
| ஊதியம் (வரவு) | | அரிசி, மளிகைப் பொருட்கள் | |
| மற்ற வருவாய் மூலங்கள் | | காய்கறி | |
| **மொத்தம்** | | **மொத்தம்** | |

2. பின் சரியான இடத்தில் குறியிடவும்:
   - [ ] வரவும் செலவும் சமமாக உள்ளது
   - [ ] வரவு செலவை விட அதிகமாக உள்ளது
   - [ ] வரவு செலவை விட குறைவாக உள்ளது

## அலகு 2: நமது நண்பர்கள்

### மதிப்பீடு (Evaluation)

**மூலப்பக்கம்:** [பக்கம் 32](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_32/page_32.html), [பக்கம் 33](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_33/page_33.html)

#### I. அடைப்புக் குறியிலிருந்து சரியான விடையைத் தேர்ந்தெடுக்க

*(சாலை, நீதிபதி, முதலுதவி, ஆசிரியர், மருத்துவர்)*

1. முறையான சிகிச்சைக்கு முன் அளிப்பது __________.

2. செவிலியர் __________ க்கு உதவி புரிவார்.

3. மக்கள் வழக்குகளுக்கு தீர்ப்பு சொல்பவர் __________.

4. நமக்கு அறிவை மேம்படுத்துபவர் _________.

5. சாலைப் பணியாளர்கள் __________ போடுகின்றனர்.

---

#### II. சரியா / தவறா என்று எழுதுக

1. தையல்காரர் என்பவர் துணி தைப்பவர்.

2. மின்பழுது செய்பவர், குழாய்களைச் சரிசெய்வார்.

3. போக்குவரத்துக் காவலர் போக்குவரத்தைக் கட்டுப்படுத்துவார்.

4. மருத்துவர் மக்களையும், உடைமைகளையும் காப்பாற்றுவார்.

5. உச்சநீதிமன்றம் நமது அரசியல் அமைப்பின் பாதுகாவலன்.

---

#### III. பின்வரும் வினாக்களுக்கு விடையளிக்க

1. நமக்கு சேவை புரிபவர்கள் சிலரைக் குறிப்பிடுக.

2. தீயணைப்பு வீரர்கள் என்பவர்கள் யார்?

3. ஒரு கட்டடப் பொறியாளரின் பணி யாது?

4. விவசாயிகள் பற்றி எழுதுக.

5. இராணுவ வீரர்கள் நமது நாட்டை எவ்வாறு பாதுகாப்பார்கள்?

---

#### IV. செயல் திட்டம் / செயல்பாடு

1. சமூக பணியாளர்களுடன் அவர்களின் உபகரணங்களைப் பொருத்தி, அவர்களின் பணியை எழுதுக.

## அலகு 4: பாதுகாப்பு

### மதிப்பீடு (Evaluation)

**மூலப்பக்கம்:** [பக்கம் 58](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_58/page_58.html), [பக்கம் 59](file:///e:/19.03.26/new%20project/tn_school_books/3rd/social_science_tm/term1/01_lessons/page_59/page_59.html)

#### I. கீழ்க்காணும் விடைகளிலிருந்து சரியானவற்றைத் தேர்ந்தெடுத்து எழுதுக

*(நீர், பாம்பு, சாலைப் போக்குவரத்து விளக்கு, மின்சாரம், தீ)*

1. தொட்டால், அது சுடும். விட்டால், அது எரியும். அது என்ன? --------

2. நான் அன்றாடம் பயன்படுத்துவேன். அதனை மழை நேரங்களில் காணேன். அது என்ன? --------

3. கம்பிகளின் வழியே செல்வேன். ஆனால் நான் கொடி அல்ல. நான் விளக்குகள் எரிய உதவுவேன். நான் யார்? --------

4. அவன் கால்கள் இல்லாமல், காடுகளில் உலாவுவான். அவன் யார்? --------

5. சாலையில் நின்று நம்மை வழி நடத்துவான். அவனுக்கு மூன்று கண்கள் உண்டு. அவன் யார்? --------

---

#### II. சரியா? தவறா? என்று எழுதுக

1. நாம் சமையலறையில் விளையாடக்கூடாது.

2. ஆற்றில் ஆழமான பகுதிக்குச் செல்லலாம்.

3. நாம் மின்சாதனங்களை ஈரமான கையால் தொடக்கூடாது.

4. நாம் நமது வீட்டையும், சுற்றுப்புறத்தையும் தூய்மையாக வைத்துக்கொள்ள வேண்டும்.

5. நாம் கண்ணாடிப் பொருட்களை வைத்து விளையாடலாம்.

---

#### III. பின்வரும் வினாக்களுக்கு விடையளிக்க

1. விபத்து நேர்வதற்கான காரணங்கள் சிலவற்றை எழுதுக.

2. நமது உடையில் தீப்பற்றினால் நாம் என்ன செய்ய வேண்டும்?

3. நாம் மின்விபத்திலிருந்து எவ்வாறு நம்மைப் பாதுகாத்துக் கொள்ள வேண்டும்?

4. நாம் எங்குச் சாலையைக் கடக்க வேண்டும்?

5. சில விஷப்பூச்சிகளின் பெயர்களைக் குறிப்பிடுக.

---

#### IV. செயல் திட்டம் / செயல்பாடு

1. சாலைப் போக்குவரத்து விளக்கு (Traffic Signal) - வண்ணம் தீட்டுவோம்:
   - நில்
   - கவனி
   - செல்

2. நீ தீபாவளி அன்று பட்டாசு வெடித்த அனுபவத்தைப் பற்றி எழுதுக.
