### அ. சரியான விடையைத் தெரிவு செய்வோமா

1. 'முயற்சி' இச்சொல்லின் பொருள் ______
   அ. ஆக்கம்
   ஆ. ஊக்கம்
   இ. இயக்கம்
   ஈ. பக்கம்

2. 'ஆன்றோர்' இச்சொல்லின் பொருள் ______
   அ. பெற்றோர்
   ஆ. உற்றோர்
   இ. சுற்றோர்
   ஈ. பெரியோர்

3. 'வைத்திருந்தனர்' இச்சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______
   அ. வைத்து + யிருந்தனர்
   ஆ. வைத் + இருந்தனர்
   இ. வைத்து + இருந்தனர்
   ஈ. வைத் + திருந்தனர்

4. 'வீதியெங்கும்' என்ற சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______
   அ. வீதி + எங்கும்
   ஆ. வீதி + யெங்கும்
   இ. வீதியெ + ங்கும்
   ஈ. வீதி + அங்கும்

5. 'நெகிழி + அற்ற' என்பதைச் சேர்த்து எழுதக் கிடைக்கும் சொல் ______
   அ. நெகிழிஅற்ற
   ஆ. நெகிழியற்ற
   இ. நெகிழ்அற்ற
   ஈ. நெகிழயற்ற

6. 'பாதிப்பு + அடைகிறது' என்பதைச் சேர்த்து எழுதக் கிடைக்கும் சொல் ______
   அ. பாதிப்அடைகிறது
   ஆ. பாதிப்புஅடைகிறது
   இ. பாதிப்படைகிறது
   ஈ. பாதிபடைகிறது

### ஆ. வினாக்களுக்கு விடையளி

1. மேரி இனி யாருடன் விளையாடப் போவதாகக் கூறினாள்?
2. பசு எதனால் இறந்தது?
3. நெகிழியினால் ஏற்படும் தீமைகள் இரண்டினை எழுதுக.
4. நெகிழி விழிப்புணர்வு வாசகம் ஒன்றினை உருவாக்குக.

### இ. பொருத்தமான சொல்லை எடுத்து நிரப்புக

1. நெகிழியற்ற ______ உருவாக்குவோம். (உலகை / உளகை)
2. நெகிழியை ஒழிப்போம் ______ காப்போம். (மன்வளம் / மண்வளம்)
3. மேரி ______ குதித்து ஓடிவந்தாள். (மகிள்வோடு / மகிழ்வோடு)
4. எறும்பு ______ கல்லும் தேயும். (ஊரக் / ஊறக்)
5. துணிப்பை என்பது ______ . (எளிதானது / எலிதானது)
