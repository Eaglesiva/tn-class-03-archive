### அ. வினாக்களுக்கு விடையளி

1. காட்டில் விலங்குகளின் கூட்டம் யார் தலைமையில் நடைபெற்றது?
2. புலிராஜா, படைத்தளபதி பொறுப்பை யாருக்குக் கொடுத்தார்?
3. ஆந்தைக்கு என்ன பதவி கொடுக்கப்பட்டது?
4. கரடி எந்தெந்த விலங்குகள் தகுதியற்றவை எனக் கூறியது?
5. இந்தக் கதையின் மூலம் நீ அறிந்து கொள்வது யாது?

### ஆ. புதிருக்குப் பொருத்தமான படத்தைப் பொருத்துக (விடையை எழுதுக)

1. இரவில் விழித்தும் பகலில் தூங்கியும் வாழ்வேன்; என் கண்களை எல்லாத்திசையிலும் திருப்புவேன். நான் யார்? — ______
2. பதுங்கிச் செல்வேன்; பாய்ந்து இரையைப் பிடிப்பேன். நான் யார்? — ______
3. என் காதுகள் நீண்டிருக்கும்; வேகமாக ஓடுவேன்; கேரட் எனக்கு மிகவும் பிடிக்கும். நான் யார்? — ______

---

### இ. முறைமாறியுள்ள சொற்களை முறைப்படுத்தித் தொடர் உருவாக்குக

1. காட்டில் / விலங்குகளின் / நடந்தது / கூட்டம்
2. இரவுக் காவல் / நீங்கள்தாம் / அமைச்சர் / ஆந்தையாரே
3. முயல் / ஓடும் / வேகமாக / அதி
4. கூடாது / யாரையும் / போடக் / எடை / குறைவாக

### ஈ. எந்த விலங்கிற்கு, எந்தப் பணி? (பொருத்துக)

| விலங்குகள் | பணிகள் |
| :--- | :--- |
| 1. சிங்கம்/புலிக்குட்டி | அ. சமையல் வேலை |
| 2. ஆந்தை | ஆ. இரவுக் காவல் |
| 3. கழுதை | இ. எச்சரிக்கைப் பணி |
| 4. முயல் | ஈ. படைத்தளபதி |
| 5. ஆமை | உ. பொருள்களைச் சேகரிக்கும் வேலை |
