### Printed page 33–34 — Evaluation exercises

1. Fill in the blanks:
   - 1 litre = _______ millilitres
   - 2 litres = _______ millilitres
   - 500 ml + 500 ml = _______ litre

2. Write in short form:
   - Litre = _______
   - Millilitre = _______

3. Circle the odd one out:
   - a) millilitre, litre, kilogram
   - b) Spoon, Bucket, Measuring tape

4. Tick the biggest unit:
   - i) 500 ml / 100 ml / 50 ml / 75 ml: _______
   - ii) 200 ml / 300 ml / 150 ml / 175 ml: _______
   - iii) 5 l / 2 l / 8 l / 7 l: _______
   - iv) 3 l / 300 ml / 30 ml / 30 l: _______

5. Circle the smallest unit:
   - i) 250 ml / 350 ml / 50 ml / 750 ml: _______
   - ii) 10 l / 3 l / 9 l / 6 l: _______
   - iii) 3 l / 350 ml / 5 ml / 40 l: _______
