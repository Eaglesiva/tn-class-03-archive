## Questions

### Printed page 58 — Practice (Systematic listing)

1. Kavin went on a tour with 2 trousers and 3 shirts. List all the possible combinations in which he can wear them.
2. List all the 2-digit numbers that can be formed using the digits 1, 2, 3 without repeating any digit.
3. List 3-letter and 4-letter English words that start with the letter 'R'.
4. List the names of animals having 4 letters in their English names.

---

### Printed page 60 — Pictograph (Fruit sales)

The picture shows data on fruits sold in a shop (Apple, Orange, Banana, Pineapple). Look at the picture and answer the questions:
1. Name the fruit which was sold more?
2. Name the fruit which was sold less?
3. Find the number of apples sold.
4. Write the number of bananas sold.
5. What is the difference in the number of pineapples sold and oranges sold?

### Printed page 61 — Practice (Chocolates sold)

| Tuesday | 4 pictures |
| Wednesday | 2 pictures |
| Thursday | 5 pictures |
| Friday | 4 pictures |
